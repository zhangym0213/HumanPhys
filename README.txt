=====================================================
 HumanPhys 项目主页 —— 使用说明
=====================================================

本文件夹是一个纯静态网页。
不需要安装软件、不需要数据库、不需要后端服务、不需要联网（图标除外）。


-----------------------------------------------------
 方式一（最简单，推荐）：直接双击打开
-----------------------------------------------------

  双击  index.html  即可用默认浏览器打开。

  · macOS   : 双击 index.html
  · Windows : 双击 index.html
  · Linux   : 双击，或在文件管理器里选择「用浏览器打开」

  这种方式不需要 Python，不需要任何准备，双击即可。


  ⚠️ 重要：必须整个文件夹一起使用
     只把 index.html 单独拿出来发出去，会变成没有排版、
     图片全部裂开的裸文字页面 —— 因为样式和图片分别在
     同目录的 style.css 和 assets/ 里。


-----------------------------------------------------
 方式二：启动本地服务器（需要把「网址」发给别人时用）
-----------------------------------------------------

  如果希望别人用浏览器输网址访问（而不是收发文件），用这个方式。

  · macOS   : 双击  start-mac-linux.command
  · Linux   : 在终端执行  bash start-mac-linux.command
  · Windows : 双击  start-windows.bat

  脚本会自动完成三件事：
    1. 找一个没被占用的端口（默认 8080，被占用则自动往后找）
    2. 打印出「本机地址」和「同网段地址」
    3. 自动打开浏览器

  需要电脑上装有 Python 3：
    · macOS 和绝大多数 Linux 自带
    · Windows 需从 https://www.python.org 下载安装，
      安装时务必勾选 "Add Python to PATH"


  ⚠️ macOS 首次双击 .command 文件，可能提示
     「无法打开，因为来自身份不明的开发者」。
     解决办法：右键点击该文件 → 选「打开」→ 弹窗里再点一次「打开」。
     只需做一次，之后就能正常双击了。


-----------------------------------------------------
 把网址发给别人时，请注意适用范围
-----------------------------------------------------

  ⚠️ 在发网址之前，请确认下面这条。这是版权/合规上很重要的一点，
     也是学术会议要求：

     论文尚未公开发布（或处于评审期）时，不建议把页面公开挂在公网。
     请先确认可以对外展示，再分享网址。若不确定，优先让对方本地打开文件。

  · 同一局域网内（同事电脑、连同一个 WiFi 的手机）
      使用脚本打印的「同网段地址」，例如 http://192.168.1.5:8080
      这个地址在同一个网络里的设备都能打开。

  · 不在同一网络的设备（异地、用手机流量）
      打不开。本地服务器没有公网地址。
      这种情况需要把文件夹部署到一台服务器上（如 nginx / 对象存储
      静态托管），或者使用内网穿透工具。


-----------------------------------------------------
 常见问题
-----------------------------------------------------

 Q: 页面上的图标（arXiv、GitHub、Database）不显示？
 A: 图标来自公共 CDN，需要能访问外网。断网或内网受限时图标不显示，
    但文字、排版、图片、表格、交互全部正常，不影响阅读和使用。

 Q: 排行榜点表头没有反应？
 A: 需要 script.js 与 index.html 在同一目录。
    请确认整个文件夹完整，没有把文件拆散或单独移动。

 Q: 左侧「Task Definition」目录点了没跳转？
 A: 同上，依赖完整文件夹结构。另外请用现代浏览器
    （Chrome / Edge / Safari / Firefox 均可，IE 不支持）。

 Q: 手机能看吗？
 A: 页面已做响应式适配，手机上排版正常。
    但手机无法直接打开电脑本地文件夹，需要：
      · 走方式二，用同网段网址在手机上访问，或
      · 把文件传到手机上，用手机浏览器打开 index.html

 Q: 打不开、或者一打开就是纯文字没有样式？
 A: 说明文件没放全。请确认 index.html、style.css、script.js
    和 assets 文件夹这四个东西在同一个目录里。


-----------------------------------------------------
 文件说明
-----------------------------------------------------

  index.html                页面结构（不要单独移动）
  style.css                 全部样式（删掉会导致页面完全没有排版）
  script.js                 交互脚本（表格排序 / 目录跳转 / 高亮跟随）
  assets/images/            6 张论文配图 + 站点图标（删掉会导致图片全裂）
  README.txt                本说明文件
  start-mac-linux.command   macOS / Linux 启动脚本
  start-windows.bat         Windows 启动脚本

  提示：整个文件夹约 5 MB。其中 assets/images 占 4.8 MB，是论文配图。
